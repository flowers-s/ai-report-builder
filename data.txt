## Parallel's Parag Agrawal: Building a New Web for AI Agents
Training Data Podcast

This episode features Parag Agrawal — former Twitter CEO, now founder of Parallel Web Systems — discussing how agents are fundamentally changing web search.
本期节目嘉宾是前推特 CEO、现 Parallel Web Systems 创始人 Parag Agrawal，探讨 Agent 如何从根本上改变网络搜索。

**核心论点 / Core Thesis**

The web was built for humans, but AI agents will use it at 1,000x the scale humans do — requiring an entirely new search infrastructure and business model built specifically for agents.
互联网是为人类构建的，但 AI Agent 使用互联网的规模将是人类的 1000 倍——这需要一套专为 Agent 打造的全新搜索基础设施和商业模式。

**关键洞察 / Key Insights**

Human click data is a bug, not a feature.
人类点击数据是一个 Bug，而非特性。

*"Our view at Parallel is that human click data is a bug, and agent doing work with search should rely on agent feedback, not human feedback."*
"我们在 Parallel 的观点是，人类点击数据是一个 Bug，执行搜索任务的 Agent 应依赖 Agent 的反馈，而非人类反馈。"

Agent feedback enables cheaper, better-quality training signals because LLMs are highly capable at compressing and evaluating information — making it possible for a startup to compete with Google-scale indices.
Agent 反馈能提供更低成本、更高质量的训练信号，因为大语言模型在信息压缩和评估方面能力极强——这让初创公司有可能与谷歌量级的索引展开竞争。

Parallel launched a search agent first, not a search product.
Parallel 首先推出了搜索 Agent，而非搜索产品。

By allowing agents to crawl the web live in response to deep-research queries (tolerating up to 10 minutes of latency), they built an incrementally growing index without requiring massive upfront infrastructure investment.
通过允许 Agent 在收到深度研究查询后实时爬取网页（可容忍最多 10 分钟的延迟），他们在无需大量前期基础设施投入的情况下，逐步构建起不断扩大的索引。

Unlearning post-PMF instincts is critical when building for a customer that doesn't yet exist.
为尚不存在的客户构建产品时，必须主动卸载已达 PMF 阶段的直觉。

Parag explicitly contrasts the data-rich feedback loops of running a scaled consumer product (Twitter) with the uncertainty of building pre-PMF infrastructure for agents — arguing that operating instincts from one context actively hurt you in the other.
Parag 明确对比了运营成熟消费产品（推特）时数据丰富的反馈循环，与为 Agent 构建 PMF 前基础设施的不确定性——他认为一种场景下的运营直觉会在另一种场景中成为负担。

**最值得关注的信号 / Most Forward-Looking Signal**

The agent is already a distinct customer category — not just a technology.
Agent 已经是一个独立的客户类别，而不仅仅是一种技术。

This reframe matters enormously: it means search infra, pricing, and business models for agents need to be designed from scratch, not retrofitted from human-facing products.
这一重新定义至关重要：它意味着 Agent 的搜索基础设施、定价和商业模式需要从零设计，而不是在面向人类的产品上打补丁。
