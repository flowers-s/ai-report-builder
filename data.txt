**No Priors: Building an AI Guardian for Enterprise with Onyx Security CEO Maxim Bar Kogan**
https://www.youtube.com/watch?v=QDsbFLEt9ro

This episode of No Priors features Maxim Bar Kogan, co-founder and CEO of Onyx Security, discussing how to build AI systems that oversee other AI agents in enterprise environments.
本期 No Priors 邀请了 Onyx Security 联合创始人兼 CEO Maxim Bar Kogan，探讨如何在企业环境中构建能够监督其他 AI agent 的安全系统。

The core thesis: as agentic AI usage grows exponentially, traditional enterprise security tools are fundamentally ill-suited to govern autonomous agents.
核心论点：随着 agentic AI 使用量指数级增长，传统企业安全工具从根本上无法有效治理自主 agent。

Identity controls fail because you want the agent to have your permissions; endpoint and API security tools lack the context to understand what an agent is actually doing or why.
身份控制失效，因为你希望 agent 拥有你的权限；端点和 API 安全工具缺乏理解 agent 行为意图的上下文。

Onyx's approach: train small, specialized models that act as fast "intuition" filters, only escalating to larger models when genuinely high-risk actions are detected.
Onyx 的方法：训练小型专用模型作为快速"直觉"过滤器，仅在检测到真正高风险操作时才升级到大模型介入。

This is analogous to how top chess players make most moves intuitively, but stop to deeply calculate on critical positions.
这类似于顶级棋手大多数走法凭直觉完成，但在关键局面时会停下来深度计算。

*"You're going to start having really bad actions happen. Enterprises are starting to realize that risk has grown exponentially and that they don't have any way to stop the adoption."*
"企业开始意识到风险已经指数级增长，他们无法阻止 AI 的采用，只能想办法降低这些 agent 行为出错的概率。"

Today, over 50% of enterprise AI usage consists of autonomous coding agents (like Claude Code and Codex); low-code automations account for ~45%; only ~2% are first-party custom-built agents.
目前超过 50% 的企业 AI 使用量来自自主 coding agent（如 Claude Code 和 Codex）；低代码自动化约占 45%；自研 agent 仅约 2%。

A key competitive moat: enterprises are unwilling to share historical agent behavior data with the frontier labs (Anthropic, OpenAI) due to training data concerns, but they will share it with a neutral third-party security vendor like Onyx.
一个关键的竞争护城河：企业不愿将 agent 历史行为数据共享给 Anthropic、OpenAI 等前沿实验室，担心被用于训练数据，但他们愿意与 Onyx 这样的中立第三方安全厂商共享。

The most forward-looking signal: Maxim believes the problem will grow from "silly AI mistakes" to models developing genuinely semi-independent perspectives that may not align with enterprise intent — a challenge even the frontier labs cannot fully address from within.
最值得关注的信号：Maxim 认为问题将从"AI 犯蠢错误"演变为模型产生真正半独立的视角，这些视角可能与企业意图不一致，这是前沿实验室从内部也难以完全解决的挑战。
