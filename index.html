核心论点

Mitch Troyanovsky 是 Basis 的联合创始人，Basis 是一家独角兽 AI 公司，其 agent 可以自主运行数小时乃至数天，已能从头到尾完成完整的报税工作。 播客开篇揭示了一个有趣细节：Basis 团队通过对麦克风低语来给 agent 提供上下文，因为说话比打字快得多，而 agent 与人类不同，更喜欢未经过滤的意识流输入。 "说话比写下来快太多了……对 agent 来说，它们不在乎。实际上它们更喜欢这种方式。" 关于为何会计是长时程 agent 的完美领域：会计本质上是将所有经济现实压缩为结构化、可审计信息的过程——它是一种对经济的智能压缩。 关于 agent 发展史：Baby AGI（2023）失败的主要原因是模型的 context window 极小，且无法在超过 20K token 后维持注意力，而非架构本身有误。 真正的突破来自 Opus 3（首个真正理解长上下文的模型）、o1（推理时计算）以及 o3（证明推理质量可通过更好的训练而非仅靠更多算力来提升）。 关于行为规范：这是一个定义 agent 行为方式的 Markdown 文件——不是 prompt，而是人类可读、评判 agent 可用于评估轨迹的规格说明。 "你会看到有人为代码文件抽象不当而崩溃，然而他们的上下文却一塌糊涂。英文提示词更珍贵，因为英文影响性能，代码不影响性能。"
