Guillermo Rauch (rauchg on X) — CEO, Vercel

He introduced gdp-ts (Ghosts of Departed Proofs for TypeScript) — a library, linter, and AI skill for safer API design.
他发布了 gdp-ts（Ghosts of Departed Proofs for TypeScript）——一个用于更安全 API 设计的库、linter 和 AI skill。
Under this contract, sensitive functions require typed "proofs" that the caller has performed an authorization check; the typechecker verifies these at compile time.
在这套机制下，敏感函数需要调用方提供类型化的"证明"，表明已执行了授权检查；类型检查器会在编译时验证这些证明。
This prevents both human developers and AI agents from shipping catastrophic security bugs.
这可以防止人类开发者和 AI agent 在不经意间发布灾难性的安全漏洞。
The key insight: agents thrive in tight loops with hard constraints that would frustrate humans, similar to how Rust's borrow checker works.
核心洞察：agent 在有严格约束的紧密循环中能发挥最佳性能，就像 Rust 的借用检查器一样，而这类约束往往会让人类开发者感到沮丧。
The README models a real Vercel product constraint: changing a Project's password requires proof of a certain role plus a certain entitlement.
README 以一个真实的 Vercel 产品约束为例：修改项目密码需要同时证明具备特定角色和特定权限。
