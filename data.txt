### The MAD Podcast with Matt Turck
**Why Every AI Agent Needs Its Own Computer | Ivan Burazin (Daytona)**

## 一、深度总结

**核心论点**
每个 AI agent 都需要自己独立的计算机（sandbox），就像每位知识工作者都需要一台电脑才能高效完成工作。
把 agent 放在共享或个人电脑上运行，会带来严重的安全风险和架构上的根本性缺陷。
Daytona 正在构建的，是专为 AI agent 设计的"可组合计算机"基础设施。

**关键洞察**
- Agent 是数字知识工作者，而知识工作者需要专属的工具和环境——让 agent 共用你的电脑，就像让新员工用你的个人账号工作，风险极高。
- 现有的容器调度方案（如 Kubernetes）并非为 agent workload 设计：agent 的计算需求极其尖锐（spike-heavy），需要毫秒级冷启动，Daytona 不得不重写自己的调度器。
- Agent stack 的分层正在清晰化：模型层 → sandbox 层 → 工具/MCP 层 → 内存层 → 编排层，每一层都有独立的赢家在涌现。
- MCP（Model Context Protocol）是当前 agent 生态最重要的基础协议，但它目前仍缺乏完善的安全模型——这是下一个需要解决的大问题。
- 全球 CPU 短缺可能比大多数人预想的更快到来：随着 agent 工作负载爆炸式增长，算力需求将远超数据中心当前的扩张速度。

**最值得关注的信号**
Ivan 指出，所有有数据壁垒的大公司都必须走向"无头化"——开放 API 和系统接口供 agent 访问——否则将面临价值的根本性萎缩。这不是技术趋势，而是生存命题。
