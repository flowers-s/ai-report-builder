核心论点

本期节目中，Coinbase CEO Brian Armstrong 与 No Priors 深入探讨加密货币、智能体金融以及长寿生物技术的未来。 **关于智能体金融（AIFi）：** Armstrong 认为 AI agent 需要拥有自己的金融账户——我们不应让 AI 成为"无银行账户"群体。 Coinbase 已构建工具，让任何 AI agent 只需一条 prompt 即可开设自托管钱包，无需 KYC，使 agent 能够自主支付商品、API 调用和 AWS 资源费用。 *"在不远的将来，agent 的数量将超过人类。由此推断，智能体经济将会超越人类经济，这是合乎逻辑的。"* 加密货币比传统支付轨道更适合 agent 的关键原因：76% 的智能体电商交易金额低于 30 美分——低于信用卡/借记卡的最低手续费门槛。 Coinbase 孵化了 X402 支付协议（现已纳入 Linux 基金会），Google、Cloudflare 和 AWS 均为合作方。 **关于万物交易所（Everything Exchange）：** Coinbase 目前 88% 的收入来自非比特币交易。 Coinbase 推出了代币化股票——这是首个真正以 1:1 实物证券托管支持（而非合成品）的产品。全球有 40 亿人无法开设美国券商账户。 Coinbase 内部预测市场在上线后数月内达到 1 亿美元年化收入，季度环比增长超过 100%。 **关于 Coinbase 的递归自我改进：** Coinbase 的内部 agent 框架（"Toshi"）正在为每个服务仓库配置"大脑"——包含事故历史、财务控制要求、A/B 测试结果和完整 PR 历史。 当 agent 进行变更、人工纠正后，纠正内容会回流到"大脑"——使未来的一次性 PR 逐步提高准确率。 Armstrong 本人现在会同时启动 10 个并行 agent 来执行复杂功能的各个阶段，在播客录制前两分钟收到完成通知。 **关于 New Limit（长寿生物技术）：** New Limit 已建立了用于表观遗传重编程的前沿 AI 模型，在南旧金山实验室开展大规模汇集筛选，寻找能恢复细胞年轻功能的化合物。 已在人源化小鼠模型中成功实现至少一种人类细胞类型的重编程；非人灵长类动物试验正在进行；首个一期临床试验将于明年启动。 初始适应症为酒精性肝病（ALD）——目前除肝移植外几乎没有有效治疗方案，属于高度未满足的医疗需求；若药物有效，预计市场规模达 200 亿美元。 长期愿景：一套针对多种细胞类型（肝脏、血管、免疫、皮肤、大脑、肌肉）的复合疗法，将其恢复到更年轻的生物学年龄，从根源上攻克与年龄相关的疾病，而非单独应对各种症状。
