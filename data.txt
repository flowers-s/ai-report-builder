**AI & I by Every — "Claude Code Can Be Your Second Brain"**

This episode features Noah Breyer, an AI strategy consultant who built an elaborate Claude Code + Obsidian setup running on a home server in his basement, accessible from his phone anywhere via Tailscale VPN.
本期节目邀请了 AI 策略顾问 Noah Breyer，他在地下室的家用服务器上搭建了一套复杂的 Claude Code + Obsidian 系统，通过 Tailscale VPN 可在任何地方用手机访问。

The core insight: Claude Code's real superpower isn't generating text — it's *reading* and navigating a large personal knowledge base.
核心洞见：Claude Code 真正的超能力不是生成文本——而是*阅读*和导航庞大的个人知识库。

Noah emphasizes that most people over-focus on AI's ability to produce artifacts and under-focus on its ability to read — which he finds far more valuable on a day-to-day basis.
Noah 强调，大多数人过于关注 AI 生成内容的能力，而忽视了其阅读能力——后者在日常使用中对他更有价值。

Key setup details:
关键搭建细节：

- Claude Code runs in the **root of his entire Obsidian vault** (not just a single project folder), giving it access to ~1,500 notes.
  Claude Code 运行在他**整个 Obsidian 知识库的根目录**（而非单个项目文件夹），可访问约 1,500 篇笔记。

- He uses a **"thinking partner" sub-agent** explicitly told never to write or draft anything — only ask questions and help explore ideas.
  他使用一个**"思维伙伴"子 agent**，明确指示其永远不要撰写或起草任何内容——只提问、帮助探索想法。

- A **daily progress agent** reviews all notes from that day and logs what was learned and how the project is evolving.
  一个**每日进度 agent** 会回顾当天的所有笔记，记录所学内容和项目进展。

- On mobile: he uses the **Termius terminal app** → SSH → home server running Claude Code on his Obsidian vault.
  在移动端：他使用 **Termius 终端 app** → SSH → 运行 Claude Code 的家用服务器。

Noah's biggest lesson: forcing models into "thinking mode" vs. "writing mode" is critical — models default to wanting to produce output, but the real value often lies in structured, iterative exploration of ideas.
Noah 的最大收获：强制模型进入"思考模式"而非"写作模式"至关重要——模型默认想要产出内容，但真正的价值往往在于对想法的结构化、迭代式探索。
