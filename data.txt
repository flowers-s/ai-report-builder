Training Data — Google DeepMind's Logan Kilpatrick: Why the Model Eats the Harness
https://www.youtube.com/watch?v=cMAs8z2dehs

Logan Kilpatrick, who leads Google AI Studio and the Gemini API at Google DeepMind, sat down with Training Data to discuss agentic AI, coding agents, world models, and Google's culture.
Logan Kilpatrick（Google DeepMind，负责 Google AI Studio 与 Gemini API）接受 Training Data 播客专访，深度探讨了 Agentic AI、编程智能体、世界模型以及 Google 内部文化。

**Core Thesis — The Model Eats the Harness**

The central argument is that "the model" is no longer just a set of weights — it has become an ever-expanding system that absorbs the scaffolding built around it.
核心论点是：「模型」已不再只是一组权重，而是不断扩展的系统，会逐渐吸收围绕其构建的所有脚手架。

Two years ago, models were simple token-in/token-out systems; today they include tool calling, hosted search, code execution, containers, and full agent harnesses.
两年前，模型只是简单的「输入 token、输出 token」；如今已囊括工具调用、托管搜索、代码执行、容器化运行以及完整的 Agent Harness。

Kilpatrick predicts that in 12 months, the agent harness itself will be digested natively into the model — the "alpha" from building your own harness will disappear.
Kilpatrick 预测，12 个月内，Agent Harness 本身将被模型原生消化，自建 Harness 的「超额收益」将会消失。

**Key Insights**

Google's Antigravity is the new through-line: just as Gemini became the common API layer across all Google products, Antigravity (the agent harness) is now rebasing every Google product to be "agent-native."
Google 的 Antigravity 是新的主线：正如 Gemini 成为所有 Google 产品的通用 API 层，Antigravity（Agent Harness）正在将每一款 Google 产品重构为「Agent 原生」。

Gemini 3.5 Flash surpassed all previous Pro models on coding — using only post-training gains, with no new pretraining run.
Gemini 3.5 Flash 仅靠后训练（post-training）优化，在编程能力上超越了所有历代 Pro 模型，无需新的预训练。

350,000 Android apps were built in AI Studio in a single week — most of them personal apps that "no one was going to build before."
单周内，AI Studio 上构建了 35 万个 Android 应用，其中大多数是个人应用，「否则根本不会有人去做」。

"Jagged superintelligence" is coming — narrow superintelligence will arrive first in domains with high verifiability (coding, math, finance, science), not as a single general leap.
「锯齿状超级智能」将率先到来——在可验证性高的领域（编程、数学、金融、科学）会率先出现垄断级能力，而非一次通用性的飞跃。

The cannibalization fear around search is misplaced: just as AI answering questions proved "incredibly positive sum" for search, agentic AI is expected to expand value rather than destroy it.
对搜索业务被蚕食的担忧是多余的：正如 AI 回答问题对搜索来说被证明是「极度正和」的，Agentic AI 同样预期会扩张而非摧毁整体价值。

**Most Forward-Looking Signal**

Keep an eye on "harness bench" — Kilpatrick floated the idea of a benchmark measuring how well models adapt to different agent harnesses, which would reframe model evaluation from raw capability to interoperability.
关注「Harness Bench」这一概念——Kilpatrick 提出了一个新基准想法：衡量模型适配不同 Agent Harness 的能力，这将把模型评估的重心从原始能力转向互操作性。
