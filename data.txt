Aaron Levie (levie on X) — CEO, Box

Box CEO Aaron Levie shared a detailed analysis of why we are now entering a true era of autonomous AI agents, identifying three key enablers.
Box CEO Aaron Levie 就我们为何正在进入真正的自主 AI 智能体时代进行了深入分析，并指出了三大关键驱动因素。

First, improved tool and computer use capabilities allow agents to access external data systems and operate software much like a human would — and where software doesn't exist, the agent simply builds it.
首先，工具使用和计算机操控能力的提升使智能体能够访问外部数据系统并像人类一样操作软件——当软件不存在时，智能体甚至可以自己构建。

Second, model capabilities are improving across vertical domains — legal, biomedical research, security, supply chain — making agent judgment calls more reliable.
其次，模型在各垂直领域（法律、生物医学研究、安全、供应链）的能力持续提升，使智能体的判断更加可靠。

Third, the surrounding infrastructure — sandboxes, file systems, data pipelines — now supports longer-running agents capable of handling arbitrarily complex tasks at enormous scale.
第三，周边基础设施（沙箱、文件系统、数据管道）现已支持长时间运行的智能体，能够处理任意复杂的任务和大规模数据。

*"You can almost imagine one or more of these systems for every role in the economy."*
*"几乎可以想象，经济中的每一个岗位都将对应一个或多个这样的系统。"*
