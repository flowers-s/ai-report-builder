**Latent Space: Designing for Agents — Zeno Rocha, Resend**
https://www.youtube.com/@LatentSpacePod

## 一、深度总结

**核心论点**
本期 Latent Space 播客邀请了 Resend CEO Zeno Rocha，探讨了一个核心问题：当 AI Agent 成为邮件基础设施的主要使用者时，邮件平台应该如何重新设计自身的产品与定位。Resend 凭借对开发者友好的 API 和卓越的产品体验，在短短几年内超越了 SendGrid，成为 AI 时代的邮件基础设施标杆。

**关键洞察**

- **Agent 原生设计哲学**：Zeno 认为，Agent 选择工具并非随机，而是因为产品的 API 设计、文档质量和开发体验真正为机器消费而优化。Resend 被 AI Agent 自发选择，恰恰证明了"为开发者设计即为 Agent 设计"的理念。

- **超越 SendGrid 的反叛之路**：Resend 在成立初期几乎人人认为不可能撼动 SendGrid 的市场地位。但通过专注于开发者体验和现代 API，Resend 不仅超越了 SendGrid 的下载量，目前已达到超过两倍的规模。

- **规模与意义的权衡**：Zeno 坦言，他宁愿经营一家 1000 万美元 ARR 的公司，也不愿经营一家 1 亿美元 ARR 但与女儿关系疏远的公司。这种创始人对生活优先级的坦诚，在当今创业文化中颇为罕见。

- **基础设施的深层重构**：Resend 正在进行一项重大的底层基础设施建设，团队已为此工作数月，即将发布重要公告。这表明 Resend 不满足于停留在 API 层，而是要向"metal"（底层基础设施）深入。

- **客户多样性揭示网络效应**：从华纳兄弟、HBO 到一个一次性注册了 2 万个域名的日本组织，Resend 的客户多样性反映了其基础设施在全球不同场景下的广泛采用。
