### Claude Blog: Building intelligent apps for Apple platforms with Claude in the Foundation Models framework

Anthropic is releasing Foundation Models framework support for Claude through a new Swift package, enabling Apple developers to call Claude for complex workflows directly from Apple's native framework.
Anthropic 正式发布通过新 Swift 包支持 Foundation Models 框架的 Claude 集成，让 Apple 开发者可以在 Apple 原生框架内直接调用 Claude 处理复杂工作流。

Apple's Foundation Models framework gives developers access to on-device models in Swift, returning typed Swift values through guided generation in as few as three lines of code.
Apple 的 Foundation Models 框架让开发者能够在 Swift 中调用设备端模型，通过引导式生成仅需三行代码即可返回类型化的 Swift 值。

Developers can now use this framework to hand off to Claude when a request calls for multi-step reasoning, code generation, web search, or code execution for data analysis.
开发者现在可以在需要多步骤推理、代码生成、网页搜索或数据分析执行代码时，将请求转交给 Claude 处理。

The integration enables seamless hybrid experiences: a journaling app can generate daily prompts on-device, then ask Claude to find threads across months of entries; a study app can define a term on-device, then hand off to Claude for deeper follow-up questions.
该集成实现了无缝的混合体验：日记应用可在设备端生成每日提示，再让 Claude 挖掘数月条目间的关联；学习应用可在设备端解释概念，再将深度追问转交 Claude 处理。

### The MAD Podcast with Matt Turck: How to Build Long-Horizon AI Agents — Mitch Troyanovsky, Basis

**深度总结**

**核心论点**
Mitch Troyanovsky，Basis（独角兽 AI 会计公司）联合创始人，系统阐述了构建真正长时程自主 AI agent 的核心方法论。他的核心论点是：在数据稀缺、过程难以验证的真实世界任务中，仅依赖结果导向的 agent 设计远远不够——你必须将人类专业流程编码为"行为规范"（behavior specs），同时让 agent 具备自我状态管理能力。

**关键洞察**

- **LLM 有超大工作记忆，但没有短期或长期记忆。** 这是长时程 agent 的根本约束。解决方案不是等模型变聪明，而是设计 harness、compaction 机制和 sub-agent 架构，让 agent 在超长 context 下保持连贯。Mitch 用电影《记忆碎片》（Memento）类比：agent 每一步推理都需要为"下一步的自己"写好笔记。

- **行为规范（Behavior Specs）比结果 eval 更重要。** 100 次 eval 全通过不代表能泛化到生产环境。以税务为例，agent 能答对问题，但如果它是从维基百科而非 IRS 原始文件得出答案，会计师不会接受这样的工作方式。好的 agent 不只需要对，还需要"做法正确"。

- **可验证性（Verifiability）是 coding agents 成功的真正原因，而非仅仅是 verifiable rewards。** 代码可以在运行时即时验证、成本极低；更重要的是，代码天然是文本形态，随处可运行。相比之下，税务 agent 面临的数据稀缺性和超长反馈循环（一份复杂报税可能需要 20+ 小时人工工作）使问题难度指数级提升。

- **"Move 37" 在真实世界 agent 中往往不是目标。** 客户购买的不是"有史以来最完美的税表"，而是一致性、可信度、可审计性——就像雇佣一个好员工，你需要的是能逐渐信任、逐步授予更多权力的稳定输出，而非偶发的天才之举。

- **Agent 构建本质上是"运行时训练数据工程"。** Context engineering 就是在推理时为模型提供高质量训练数据。将 context 视为训练数据，而非"写了些 prompt"——这是 Mitch 最核心的心智模型转变。

**最值得关注的信号**
Mitch 提到正在研究将行为规范直接用于底层模型的 post-training（类似 process reward model），这是下一个重要研究方向。如果成功，将让 agent 在无需人工 harness 的情况下自然地遵循领域流程——watch this space。
