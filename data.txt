## Claude Official (@claudeai)

Claude's official account announced two significant new agentic features — Outcomes and Dreaming — pointing toward a future of self-improving, quality-controlled AI agents.
Claude 官方账号宣布了两项重要的 Agent 新功能——Outcomes（结果评估）和 Dreaming（梦境学习）——指向自我改进、质量可控的 AI Agent 未来。

**Outcomes** lets developers set quality rubrics. A separate grader model evaluates agent output, and the agent iterates until it meets the bar. Subscribe to webhooks for async completion notifications.
**Outcomes** 允许开发者设定质量评分标准，由独立的评分模型检查输出，Agent 持续迭代直到达标；支持通过 webhook 订阅异步完成通知。

**Dreaming** reviews an agent's past sessions, extracts behavioral patterns, and curates memories — so agents can *learn over time* from their own history, not just from each individual run.
**Dreaming** 回顾 Agent 的历史会话，提取行为模式并整理记忆——让 Agent 能够随时间推移从自身经历中持续学习，而不仅限于单次运行。

## 🎙️ Podcast: Training Data — "Anthropic's Boris Cherny: Coding's Printing Press Moment"

**Source:** Training Data (Anthropic)
**URL:** https://www.youtube.com/playlist?list=PLOhHNjZItNnMm5tdW61JpnyxeYH5NDDx8

---

### 一、深度总结

**核心论点**

Boris Cherny，Claude Code 的创造者，认为"编程已经被解决了"——至少对于简单的代码库而言如此。他本人今年一行代码都没有手写，每天通过 AI agent 提交数十个 PR，最高纪录是一天 150 个。更深远的观点是：编程正在成为一种新型读写能力，就像印刷术将阅读从精英普及到大众一样，AI 编程工具将让每个人都能构建软件。

**关键洞察**

- **"产品过剩"（Product Overhang）是真实存在的。** 模型能力已经领先于产品形态。Claude Code 诞生于这一洞察：与其等产品成熟，不如为下一代模型构建，接受前期无 PMF 的阵痛。
- **语言和框架的选择曾经至关重要，现在几乎无所谓。** 早期选 TypeScript + React 是因为模型对它们的"分布"最熟悉；如今模型能学习任何新语言、新框架。
- **Boris 每晚运行"数千个" agent。** 这不是夸张，而是 AI 原生工作流的真实状态——人睡觉，机器工作。
- **iPhone 成为主要编程设备。** Boris 现在主要在手机上使用 Claude Code，这意味着移动端 AI 编程界面的潜力巨大且未被充分开发。
- **编程即将成为基础素养。** 就像印刷术让阅读从贵族特权变为普及技能，AI coding 工具将把软件构建能力赋予所有人——这是一个十年维度的文明级转变。

---

### 二、Bilingual Deep Dive (Sentence-by-Sentence)

Boris Cherny created Claude Code almost by accident, joining a small internal incubator team at Anthropic in late 2024.
Boris Cherny 近乎"偶然"地创建了 Claude Code——2024 年底，他加入了 Anthropic 内部一个名为 Anthropic Labs 的小型孵化团队。

That team of just a few people went on to create Claude Code, MCP, and the Anthropic desktop app.
这个只有寥寥数人的团队，最终创造了 Claude Code、MCP 协议和 Anthropic 桌面应用。

The core insight was "product overhang" — the model could already do far more than any product had captured.
核心洞察是"产品过剩"——模型的能力已远超现有产品所能实现的边界。

In late 2024, the state of the art in AI coding was tab-completion, one line at a time.
2024 年底，AI 编程的最前沿还是逐行补全的 Tab 键自动完成。

Boris felt the model was ready for a much bigger leap: having the agent write all the code.
Boris 认为模型已准备好迈出更大的一步：让 agent 直接写完所有代码。

For the first six months, it didn't really work — barely used for 10% of his code.
最初六个月，效果并不理想——他自己也只将其用于约 10% 的代码。

The product didn't have its PMF moment because it was being built for the *next* model, not the current one.
这款产品迟迟未能找到 PMF，因为它是为下一代模型而构建的，而非针对当前模型。

The exponential growth started with Opus 4, then inflected further with each subsequent model release.
指数级增长始于 Opus 4，此后每次新模型发布都会带来新一轮拐点。

Today, Boris writes zero lines of code by hand — the model writes 100% of his code.
如今，Boris 一行代码都不手写——所有代码 100% 由模型生成。

He submits dozens of PRs every day, with a personal record of 150 PRs in a single day.
他每天提交数十个 PR，个人记录是单日 150 个 PR。

He now uses Claude Code primarily on iOS — a sign that mobile AI coding is not a gimmick but a serious workflow.
他现在主要在 iOS 上使用 Claude Code——这表明移动端 AI 编程不是噱头，而是真实可用的严肃工作流。

He runs thousands of agents overnight, letting the machines work while he sleeps.
他每晚运行数千个 agent，让机器在他睡觉时持续工作。

The TypeScript + React stack for Claude Code was deliberately chosen because it was "on distribution" for the model.
Claude Code 选用 TypeScript + React 技术栈，是因为这些语言和框架在模型的训练分布中高度覆盖。

Today that hardly matters — models can pick up any language or framework they haven't seen before.
如今这几乎不再重要——模型可以自行学习任何从未见过的语言或框架。

Boris's boldest claim: coding is like a "printing press moment."
Boris 最大胆的断言：编程正处于一个"印刷术时刻"。

Just as the printing press democratized reading and writing, AI will democratize the ability to build software.
正如印刷术让阅读与写作从贵族特权走向大众，AI 将让构建软件的能力普及到每一个人。

Coding will become the new literacy — not a specialized skill, but a fundamental human capability.
编程将成为新的读写能力——不再是专业技能，而是人类的基础素养。
