### Anthropic Engineering

**An update on recent Claude Code quality reports**
https://www.anthropic.com/engineering/april-23-postmortem

Anthropic has traced months of reported Claude Code quality regressions to three separate changes that affected Claude Code, the Claude Agent SDK, and Claude Cowork.
Anthropic 追踪发现，数月以来关于 Claude Code 质量下滑的报告，源于三处独立变更，影响了 Claude Code、Claude Agent SDK 和 Claude Cowork。

The first issue: on March 4, the default reasoning effort was lowered from "high" to "medium" to reduce latency — but users quickly noticed lower intelligence and the change was reverted on April 7.
第一个问题：3 月 4 日，默认推理强度从"high"降至"medium"以减少延迟，但用户很快发现智能水平下降，该变更已于 4 月 7 日回滚。

All users now default to "xhigh" effort for Opus 4.7 and "high" for all other models.
目前所有用户对 Opus 4.7 默认使用"xhigh"强度，其他模型默认使用"high"强度。

The second issue: on March 26, a caching optimization introduced a bug that wiped Claude's prior reasoning on every turn after a session went idle for over an hour.
第二个问题：3 月 26 日，一处缓存优化引入了一个 bug，导致会话空闲超一小时后，每轮对话的历史推理均被清除。

This caused the forgetfulness, repetitive behavior, and odd tool choices users reported — and also caused faster-than-expected usage limit drain due to repeated cache misses.
这导致了用户反馈的"健忘"、重复行为和奇怪工具调用，并因反复缓存未命中而导致用量限额消耗异常加速。

It was fixed on April 10.
该问题已于 4 月 10 日修复。

The third issue: on April 16, a system prompt addition to reduce verbosity ("keep text between tool calls to ≤25 words") caused a 3% drop in coding quality and was reverted on April 20.
第三个问题：4 月 16 日，为减少冗余输出新增的系统提示（"工具调用之间文本不超过 25 字"）导致代码质量下降 3%，已于 4 月 20 日回滚。

Going forward, Anthropic will require a broader eval suite for every system prompt change, add soak periods and gradual rollouts, ensure internal staff use the public build, and improve Code Review tooling.
未来，Anthropic 将对每次系统提示变更要求更广泛的评估套件，增加浸泡期和灰度发布流程，确保内部员工使用公开版本，并改进 Code Review 工具。

As of April 23, usage limits have been reset for all subscribers.
自 4 月 23 日起，所有订阅用户的用量限额已重置。

**Scaling Managed Agents: Decoupling the brain from the hands**
https://www.anthropic.com/engineering/managed-agents

Anthropic Engineering has published an in-depth technical post on how they architected Claude Managed Agents — a hosted service for running long-horizon agents — around the principle of decoupling the "brain" (Claude + harness) from the "hands" (sandboxes and tools).
Anthropic Engineering 发布了一篇深度技术文章，介绍了 Claude Managed Agents 的架构设计——这是一项运行长时程 agent 的托管服务，核心原则是将"大脑"（Claude + harness）与"双手"（沙箱和工具）彻底解耦。

The original monolithic design put all agent components in a single container — a "pet" that was painful to debug and impossible to scale without coupling users' infrastructure to Anthropic's.
最初的单体设计将所有 agent 组件放在一个容器中——这是一个"宠物"服务器，难以调试，且无法在不绑定用户基础设施的情况下扩展。

By separating session (event log), harness (orchestration loop), and sandbox (execution environment) into independent interfaces, each component became "cattle" — recoverable and replaceable without data loss.
通过将 session（事件日志）、harness（编排循环）和 sandbox（执行环境）分离为独立接口，每个组件都成为"牲口"——可恢复、可替换，且不会丢失数据。

The result: p50 time-to-first-token (TTFT) dropped ~60% and p95 dropped over 90%, because containers are now provisioned on-demand rather than upfront for every session.
结果：p50 首 token 延迟（TTFT）降低约 60%，p95 降低超过 90%，因为容器现在按需供应，而非对每个会话提前预置。

The security model was also improved: sandboxes never hold credentials directly; Git tokens are injected at clone time, and OAuth tokens for MCP tools are held in a vault accessed only through a dedicated proxy.
安全模型也得到改善：沙箱不再直接持有凭证；Git token 在克隆时注入，MCP 工具的 OAuth token 保存在专用 vault 中，仅通过专属代理访问。

The session log is explicitly not Claude's context window — it is a durable external store that the harness can interrogate via getEvents(), enabling selective replay and context engineering without irreversible decisions.
session 日志明确不是 Claude 的上下文窗口——它是一个持久化的外部存储，harness 可通过 getEvents() 查询，实现选择性回放和上下文工程，无需做出不可逆的决策。

### Claude Blog

**New in Claude Managed Agents: self-hosted sandboxes and MCP tunnels**
https://claude.com/blog/claude-managed-agents-updates

Claude Managed Agents now supports two major enterprise features: self-hosted sandboxes and MCP tunnels.
Claude Managed Agents 现已支持两项重要企业功能：自托管沙箱（self-hosted sandboxes）和 MCP 隧道（MCP tunnels）。

With self-hosted sandboxes, the agent's execution environment runs on your own infrastructure or with managed providers (Cloudflare, Daytona, Modal, or Vercel), while Anthropic's infrastructure handles orchestration, context, and error recovery.
通过自托管沙箱，agent 的执行环境运行在用户自己的基础设施或托管服务商（Cloudflare、Daytona、Modal、Vercel）上，而 Anthropic 的基础设施负责编排、上下文管理和错误恢复。

Sensitive files, packages, and services never leave your perimeter — your existing network policies, audit logs, and security tooling apply automatically.
敏感文件、软件包和服务始终不离开用户网络边界——现有的网络策略、审计日志和安全工具自动生效。

With MCP tunnels, agents can reach MCP servers inside your private network without exposing them to the public internet — a lightweight gateway makes a single outbound connection with no inbound firewall rules required.
通过 MCP 隧道，agent 可以访问私有网络内的 MCP 服务器，无需将其暴露到公网——一个轻量级网关仅需一条出站连接，无需开放任何入站防火墙规则。

Self-hosted sandboxes is available in public beta; MCP tunnels is in research preview (access by request).
自托管沙箱现已进入公开 beta；MCP 隧道处于研究预览阶段（需申请访问权限）。

### AI & I by Every

**We Automated Everything With AI and Tripled Our Headcount**
https://www.youtube.com/watch?v=dCmOTURRf1Y

Every CEO Dan Shipper and COO Brandon discuss Dan's essay "After Automation," arguing that AI creates more human work rather than eliminating it.
Every CEO Dan Shipper 与 COO Brandon 讨论了 Dan 的文章《After Automation》，论证 AI 创造了更多人类工作，而非消灭它们。

The core thesis: AI makes "yesterday's expert competence cheap," flooding the zone with work that is "close but not quite right," which in turn increases demand for experts to build systems and shepherd that output into something actually good.
核心论点：AI 让"昨日的专家能力变得廉价"，涌现出大量"接近但不够准确"的工作产出，这反而增加了对专家的需求——他们需要构建系统，并将这些输出打磨成真正可用的成果。

Every has grown from 4 to 30 people since GPT-3, despite being "as AI-native as it gets" — swinging a stick in their Slack is "as likely to hit a human as an agent."
尽管 Every 在 AI 应用上堪称"极度原生"——在他们的 Slack 里随便打一棒子，"碰到人类的概率和碰到 agent 一样高"——公司自 GPT-3 时代以来仍从 4 人扩张至 30 人。

"The further away an agent gets from a human, the less valuable it is."
"agent 离人类越远，它的价值就越低。"

Dan's workflow tip for long-form writing: every morning, monologue the entire argument into a document, then use Claude to ask "what am I really trying to say?" — building a log of successive approximations toward the core idea.
Dan 的长文写作技巧：每天早晨将完整论点独白录入文档，再用 Claude 追问"我到底想说什么"——逐步积累出一份向核心观点不断逼近的记录。

He also had Codex convert each draft into a podcast audio file to listen to on his commute, identifying problems and next steps without re-reading.
他还让 Codex 将每个草稿转成播客音频，在通勤途中收听，无需重新阅读即可发现问题和明确下一步。

On the ClickUp layoffs (22% of workforce): "When companies don't do well, they lay people off. And then blame AI."
关于 ClickUp 裁员（裁减 22% 员工）："公司经营不善就裁人，然后把锅甩给 AI。"

The takeaway: "If you just ride the models — when new models come out, learn to use them for the stuff that you do — you're going to be fine."
结语："只要跟上模型——每当新模型发布，就学着把它用到你的工作中——你就没问题。"
