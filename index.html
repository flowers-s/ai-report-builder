### Latent Space: "Using Agents for Long-Horizon Financial Work — Aman Singh, Arca"

来源 ### Latent Space
跳转链接 →

核心论点

Arca 不是一家 SaaS 公司——它本身就是一家从第一天起就以 AI 原生方式构建的财富管理公司。 这一区别至关重要：它意味着 Arca 可以将内部工作方式标准化，使 agent 能够参与可预测、高可信度的工作流程。 **Aman Singh 的核心洞见**："Agent 触发人的次数，多于人触发 Agent 的次数。" 这些 Agent 全天候运行，主动监控每位客户的财务状况——市场动态、截止日期、税务风险、漏掉的 RMD——并在恰当时机将合适的人类顾问拉入流程。 **关于模型选择**：Arca 以 Claude 为主力模型，并采用基于层级的路由策略——复杂任务（如税务分析）使用更强的模型，后台活动则使用更轻量的模型。 他们刻意避免依赖任何单一服务商的托管 Agent 基础设施，选择自主掌控内存与编排层。 **关于长周期任务（10 天流程）**：Arca 为每位客户构建了持久化记忆系统，追踪当前状态、负责人、下一步行动和长期目标。 每晚运行的"梦境进程"会对每位客户的世界状态进行反思并更新记忆，使任何新唤醒的 Agent 都能迅速掌握全局。 **关于安全**：所有安全限制均为完全确定性的。 Agent 无法自主执行交易或转移资金——所有后果性操作都要求人类在回路中。 每次数据库写入都会触发基于 LLM 的验证调用；外部输入（邮件、文档、电话）在边缘进行提示注入扫描。 **关于合规与可审计性**：每个 Agent 操作都会生成变更日志——记录什么被更改、谁更改的、从哪个系统组件更改、以及何时更改。 这同样适用于人类操作，为 Agent 和顾问创建了统一的可审计性。 **关于反馈循环**：员工的每次编辑或取消操作都被记录为评估数据。 每晚，一个元 Agent 会审查真实世界的 trace 和反馈，并提出对 harness 的改进建议——但在发布前，人类工程师仍需审批提示词变更。 **最值得关注的前瞻信号**：Arca 正在证明，AI 原生服务真正的竞争护城河在于*掌控智能层*——内存系统、运营知识与编排能力——而非将其外包给基础模型提供商。 随着基础模型实验室（包括 Anthropic）进军金融服务领域，掌控自身 Agent harness 的公司将比使用现成托管 Agent 的公司拥有结构性优势。
