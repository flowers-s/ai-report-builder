## 🎙️ PODCAST: Inside Stainless — The Developer Tools Startup Anthropic Just Bought for $300 Million

**AI & I by Every (Dan Shipper × Alex Rattray)**

This episode from AI & I went deep on MCP (Model Context Protocol) with Alex Rattray, founder and CEO of Stainless — the company Anthropic just acquired for ~$300M.
这期《AI & I》节目与 Stainless 创始人兼 CEO Alex Rattray 深入探讨了 MCP（模型上下文协议）——而就在发布后不久，Anthropic 以约 3 亿美元完成了对这家公司的收购。

**The core argument:** The internet was built for humans and traditional software, not for AI agents. MCP is the new protocol connecting LLMs to the web — but it's not working well yet, and Stainless is building the infrastructure to fix that.
**核心论点：** 互联网的架构是为人类和传统软件设计的，而非为 AI Agent。MCP 是连接 LLM 与互联网的新协议——但目前运行并不理想，Stainless 正在构建修复这一问题的基础设施。

**Key insights:**
**关键洞察：**

• **MCP context problem is real.** Exposing a full API like Stripe's to an LLM via MCP can burn hundreds of thousands of tokens just in tool definitions — far too much for today's context windows.
• **MCP 的上下文问题切实存在。** 通过 MCP 向 LLM 暴露像 Stripe 这样完整的 API，光是工具定义就可能消耗数十万 token——远超今日上下文窗口的承载上限。

• **The future is code execution, not tool lists.** Instead of 50 discrete MCP tools, give the model a code execution sandbox with an SDK and two tools: "run code" and "search docs." The model writes API calls directly, dramatically reducing context usage and enabling far more flexible automation.
• **未来属于代码执行，而非工具列表。** 与其提供 50 个离散的 MCP 工具，不如给模型一个配备 SDK 的代码执行沙箱，只需两个工具："执行代码"和"搜索文档"。模型直接编写 API 调用，大幅降低上下文消耗，同时实现更灵活的自动化。

• **Security must live at the API layer.** OAuth with granular scopes — not MCP-level restrictions — is the right security model. Limiting what's exposed through MCP is a band-aid; the real fix is proper API-layer permissions.
• **安全机制必须落在 API 层。** 细粒度 OAuth 权限范围——而非 MCP 层面的限制——才是正确的安全模型。限制 MCP 暴露的内容只是治标之策，真正的解决方案是完善的 API 层权限控制。

• **"Cyborg AI" is the real vision.** The most powerful agents will be hybrids: part neural net, part deterministic code. One-off agentic tasks will blur into persistent production software as useful agent actions get committed to repos.
• **"赛博格 AI"才是真正的愿景。** 最强大的 Agent 将是混合体：一半神经网络，一半确定性代码。一次性的 Agent 任务将逐渐演变为持久的生产软件——随着有价值的 Agent 行为被提交到代码库中沉淀。

• **Good MCP design is hard product management.** Keep tool count small, keep names and descriptions precise, keep input/output schemas minimal. It's like writing great copy — deceptively simple, actually hard.
• **优秀的 MCP 设计本质上是扎实的产品管理。** 保持工具数量精简，工具名称与描述精准，输入/输出 schema 最小化。这就像写一篇好文案——看似简单，实则极难。
