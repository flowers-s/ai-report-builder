### AI & I by Every — "GitHub's COO Explains Why AI Hasn't Replaced Developers"

**深度总结**

**核心论点**
GitHub COO Kyle Daigle argues that AI agents are rapidly expanding who counts as a "developer," and that GitHub's core role is to support every builder's "agent moment" — not just GitHub Copilot users.
GitHub COO Kyle Daigle 认为，AI agent 正在迅速扩展"开发者"的定义，GitHub 的核心使命是支持每位构建者的"agent 时刻"，而不仅仅是 GitHub Copilot 用户。

GitHub is now seeing 17 million agent-created pull requests per month — and the growth shows no sign of plateauing.
GitHub 目前每月看到 1700 万个由 agent 创建的 Pull Request，且增长没有放缓的迹象。

**关键洞察**

The scale of agentic activity on GitHub is staggering: on track for 14 billion commits in 2026 if growth were linear (it isn't), versus 1 billion for all of 2025.
GitHub 上 agent 活动的规模令人震惊：若按线性增长，2026 年有望达到 140 亿次提交（实际增长非线性），而 2025 年全年仅 10 亿次。

Open source maintainers are drowning in agent-generated PRs, and GitHub is building maintainer-first tools — agentic code review, automated merge pipelines — while deliberately letting communities set their own standards rather than imposing one top-down.
开源维护者正被 agent 生成的 PR 淹没，GitHub 正在构建以维护者为先的工具——agent 化的代码审查、自动合并流程——同时刻意让社区自己制定标准，而不是自上而下强制推行。

The business model is evolving: freemium made sense in a human-centered world where people sleep, but agents work around the clock, pushing toward usage-based pricing. GitHub wants to enable heavy agent usage while preserving a strong core experience for individual developers.
商业模式正在演变：在以人为中心、人需要睡觉的世界里，免费增值模式是合理的，但 agent 全天候工作，推动定价向用量计费方向转变。GitHub 希望在支持大量 agent 使用的同时，为个人开发者保留强大的核心体验。

Kyle Daigle's new dual role as GitHub COO and Microsoft's Chief Marketing Officer for Developer is deliberately focused on "developer choice" and avoiding the "mousetrap" of locked-in ecosystems — making it easy to use GitHub alongside any tool, including competitors.
Kyle Daigle 的新双重身份——GitHub COO 兼微软开发者首席营销官——刻意聚焦于"开发者选择权"，避免锁定生态的"捕鼠夹"效应，使 GitHub 能与任何工具（包括竞品）无缝配合。

This year's Microsoft Build deliberately featured external community speakers in keynotes (e.g., Swix, Peter Steinberger) for the first time — a sign that even Microsoft's biggest developer conference is moving away from a single-vendor narrative.
今年的 Microsoft Build 首次刻意在主题演讲中邀请了外部社区演讲者（如 Swix、Peter Steinberger）——这表明即便是微软最重要的开发者大会，也正在摆脱单一厂商叙事。

**最值得关注的信号**
The 17M agent PRs per month number is the clearest signal yet that we've exited the "early adopter" phase of agentic coding — and GitHub is betting heavily that growth will compound, not plateau.
每月 1700 万个 agent PR 是迄今为止最清晰的信号，表明我们已经离开了 agent 编程的"早期采用者"阶段——GitHub 正在大力押注增长将持续复合，而非趋于平稳。
